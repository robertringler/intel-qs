# PayeeProof

**Payee assurance and ACH fraud-monitoring evidence for mid-market companies.**

PayeeProof stops vendor-impersonation fraud (business email compromise) in three ways:
1. It locks the vendor master: new or changed bank details require out-of-band verification and independent approval.
2. It screens every NACHA payment file before release.
3. It keeps a tamper-evident record of every control, which serves as the documented, risk-based fraud monitoring
   that Nacha has required of every business ACH originator since 22 June 2026.

This directory is a self-contained venture: research → selection → product. The parent repository (Intel
Quantum Simulator) is untouched.

## Quick start (development)

```bash
uv venv .venv && uv pip install -p .venv -r requirements-dev.lock && uv pip install -p .venv -e . --no-deps
python scripts/pgcluster.py start /tmp/pp-pg 54329           # or use any PostgreSQL 14+
export PP_OWNER_DB_PASSWORD=owner PP_APP_DB_PASSWORD=app
.venv/bin/payeeproof provision-db --admin-url postgresql://pgadmin@127.0.0.1:54329/postgres
eval "$(.venv/bin/payeeproof gen-keys | sed 's/^/export /')"
export PP_MIGRATION_DATABASE_URL=postgresql+psycopg://payeeproof_owner:owner@127.0.0.1:54329/payeeproof
export PP_DATABASE_URL=postgresql+psycopg://payeeproof_app:app@127.0.0.1:54329/payeeproof
export PP_COOKIE_SECURE=false PP_BASE_URL=http://localhost:8000
.venv/bin/payeeproof migrate && .venv/bin/payeeproof serve --workers 1 &
.venv/bin/payeeproof worker
```
